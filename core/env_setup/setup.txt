1) Create the maintained Python environment:
   conda env create --file environment.modern.yml
   conda activate carla_modern

2) Use the Python API shipped with the external CARLA 0.9.14 installation:
   export CARLA_ROOT=/path/to/CARLA_0.9.14
   export PYTHONPATH="$CARLA_ROOT/PythonAPI/carla:$CARLA_ROOT/PythonAPI/carla/agents:${PYTHONPATH:-}"

3) Install the system libraries required by the selected CasADi build, when
   applicable (for example SLICOT on Linux).

4) Install and license Gurobi separately. Verify the conic plugin used here:
   python -c "import casadi as ca; print(ca.has_conic('gurobi'))"

CARLA simulator binaries, model assets and Gurobi licence files are external
and must not be committed to this repository. See ../../REPRODUCIBILITY.md.
