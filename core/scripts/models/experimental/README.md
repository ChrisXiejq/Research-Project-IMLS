# Experimental process files

This directory contains historical training stages, audit utilities,
post-processing steps, snapshots and milestone-specific implementations.
Internal day, revision and version identifiers are preserved only so recorded
experiments can still be traced.

These files are not the public entry points. Use
`../run_offline_experiment.sh`, `../train_prediction_model.py` and
`../evaluate_prediction_model.py` for maintained workflows.
