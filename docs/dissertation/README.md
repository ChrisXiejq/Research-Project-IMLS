# Dissertation workspace

- `Marking Rubric - Dissertation.pdf`: supplied UCL marking rubric.
- `latex/`: canonical TMLR-format dissertation source and complete section
  skeleton.

Start with [`latex/README.md`](latex/README.md), then use
[`latex/WRITING_CHECKLIST.md`](latex/WRITING_CHECKLIST.md) as the drafting order
and [`latex/RUBRIC_TO_STRUCTURE.md`](latex/RUBRIC_TO_STRUCTURE.md) as the
quality gate.

The dissertation source reads frozen numerical evidence and figures from
`../paper/generated/paper_assets_v1/`. Experimental records remain canonical
under `docs/paper`; do not duplicate or manually alter them in this directory.
