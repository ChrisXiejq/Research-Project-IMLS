# 最终研究问题与实验方法

## 1. 当前研究定位

实验阶段已完成到 **Day14**。项目不是单纯证明 adaptive risk 优于 fixed risk，也不是证明 Transformer 必然更强，而是研究：

> 任务适配和显式交互建模如何改善受控 give-way 场景中的轨迹预测，以及预测器的离线性能如何通过 risk allocation、trajectory solver 与 safety supervisor 共同影响闭环安全—效率表现。

推荐标题：

> **Task-Adapted Motion Prediction and Predictor–Risk Coupling for Give-Way Intersection Planning in CARLA**

相比原来的 “Interaction-Aware Prediction” 标题，这个标题更准确：最终选中的 B1 是 task-adapted model，并不读取显式 interaction sequence；T1/T2 只作为被认真检验但未胜出的 interaction-aware alternatives。

## 2. Research questions

### RQ1：任务适配是否改善同分布 give-way 轨迹预测？

- B0：pretrained MultiPath control；
- B1：只重新训练最终 prediction head 的 task-adapted MultiPath；
- 指标：rollout-macro trajectory mixture NLL、top-1 ADE/FDE；
- 目标：区分“预训练模型可部署”与“场景适配真正改善预测”。

### RQ2：显式交互序列和 Transformer 是否提供超出容量增加的收益？

- B2-M ↔ T1：mean-only matched pair；
- B2-D ↔ T2：distributional matched pair；
- B1：simple adaptation control；
- zero/shuffle sequence ablation：只用于判断模型是否实际使用 sequence，不用于重新选模。

### RQ3：离线预测改善是否稳定转化为闭环收益？

- 比较 B0 与冻结 B1 predictor stack；
- 在 risk policy、target style 和 arrival timing 条件下进行 paired closed-loop evaluation；
- 同时报告 efficiency、footprint separation、solver feasibility 和 supervisor activity。

### RQ4：adaptive risk 是否普遍支配 fixed-risk frontier？

- fixed control 不是单一点，而是 aggressive/medium/conservative frontier；
- adaptive 必须同时在 safety 和 efficiency 上优于 frontier 才能称为 dominance；
- 若只在局部条件改善一个指标，应解释为 conditional trade-off。

## 4. CARLA scenario 与数据协议

- 场景：Town05 中受控 give-way intersection；
- target styles：assertive 与 reactive；
- collection policies：fixed 与 adaptive；
- collection：200 rollouts，每个 ego init 对应四个 factorial cells；
- history：6 tokens，覆盖 `−1.0` 至 `0.0 s`；
- 每个 token：12 个相对位置、速度、yaw 和距离特征；
- prediction horizon：10 steps × `0.2 s = 2.0 s`；
- 坐标系：current target-local right-handed frame；
- raster：共享 online/offline byte-channel 与 ResNet preprocessing contract；
- 禁止输入：target style、ego policy、cell ID、split、ego init ID。

### 4.1 Rollout-level split

| Split | Init IDs | Rollouts | Raw windows | Usable windows | Full horizon |
| --- | --- | ---: | ---: | ---: | ---: |
| Train | 1–40 | 160 | 9121 | 4036 | 2596 |

## 5. Model variants

| Variant | Sequence encoder | Trainable output | Experimental role |
| --- | --- | --- | --- |
| B0 | none | none | pretrained offline/closed-loop control |
| B1 | none | final MultiPath Dense head | simple task adaptation |
| B2-M | flattened sequence + matched MLP | trajectory means | T1 capacity control |
| B2-D | flattened sequence + matched MLP | means/covariance/orientation/logits | T2 capacity control |
| T1 | masked Transformer | trajectory means | mean-only attention model |
| T2 | masked Transformer | full distributional residual | distributional attention model |

所有 Day8 candidates 使用同一 split、anchors、GMM decoding、loss、epoch budget、three seeds 和 validation ranking metric。B2-M/T1 参数差异约 10.48%，B2-D/T2 约 5.89%，低于预注册的 20% matched-capacity 上限。

## 6. Offline selection protocol

1. `5 variants × 3 seeds = 15` validation runs；
2. primary selection metric：validation rollout-macro mixture NLL per step；
3. representative seed 只能由 validation 选择；
4. validation selection 冻结后才访问 test；
5. frozen test 不允许重新训练、调参或改变 calibration；
6. context ablation、B0 bridge 和 Day13 都是 post-selection reporting/sensitivity。

## 7. Closed-loop protocol

### Day9 deployment gate

8/8 smoke arms 用于验证输入、GMM、calibration、prediction→risk→solver→supervisor 链可执行。它不是正式效果实验。

### Day10 nominal matrix

`2 predictors × 4 risk policies × 2 target styles × 5 inits = 80 rollouts`。

### Day11 shifted-timing matrix

`2 predictors × 2 risk policies × 2 target styles × 2 offsets × 5 inits = 80 rollouts`，offset 为 `−3 m/+3 m`。

### Day12 synthesis

合并 nominal `0 m` 与 shifted `±3 m` 中匹配的 fixed-medium/adaptive conditions，共 24 cells、120 formal rollouts。

### Treatment definition

闭环 B0 使用 identity calibration；B1 使用 validation-frozen temperature/covariance calibration。因此闭环 predictor contrast 的准确处理变量是 **frozen predictor stack（model + calibration）**，不能只归因于 neural-network weights。

## 8. Metrics 与统计单位

### Offline

- rollout-macro mixture NLL per step；
- top-1 ADE/FDE；
- calibration coverage MAE；
- assertive、reactive、response-active subsets。

### Closed loop

- target-clearance-adjusted completion delay；
- minimum footprint separation；
- solver failure fraction；
- supervisor active fraction；
- observed footprint collision/yield-order/completion failures。

### Inference

- effect means 可使用全部 balanced paired conditions；
- uncertainty 与 exact sign-flip test 必须在 5 个 ego-init cluster means 上计算；
- simulator steps、windows、target styles 不作为独立样本；
- 5 clusters 下最小双侧 exact p 为 `0.0625`；
- Holm correction 在每个预定义 inference scope 内控制 multiplicity；
- bootstrap interval 即使不跨零，也不能在 exact/Holm test 不支持时写成传统显著性发现。
