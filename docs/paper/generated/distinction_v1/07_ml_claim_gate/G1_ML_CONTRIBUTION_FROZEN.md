# G1 — Frozen machine-learning contribution

> Under a frozen small-data give-way protocol, output-head task adaptation produced a large aggregate in-distribution prediction gain beyond simple physical baselines, while lightweight Transformer residual adapters did not establish a consistent advantage over corresponding MLP adapters. The aggregate gain did not extend to the rare, timing-shifted response-active tail, and closed-loop policy effects remained coupled to calibration, supervisor and operating context.

## Claim decisions

| ID | Verdict | Frozen claim boundary |
| --- | --- | --- |
| ML-C1 | supported_descriptively | single Town05 give-way distribution; five held-out init groups; B1 is a complete adaptation configuration |
| ML-C2 | not_supported | comparisons are not parameter matched and 10/15 runs reached the epoch ceiling |
| ML-C3 | refuted_by_posthoc_tail_diagnostic | response-active windows are outcome-dependent and post hoc; -3 m tail is the clearest failure |
| ML-C4 | partially_supported_or_inconclusive | shuffle sensitivity is not proof of semantic or causal understanding; neutralisation is OOD |
