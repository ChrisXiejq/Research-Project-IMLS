# 论文写作路线与章节大纲

本文件说明“写什么”；执行关卡见
[`../dissertation/FINAL_TO_SUBMISSION_PLAN.md`](../dissertation/FINAL_TO_SUBMISSION_PLAN.md)。

## 1. 写作顺序

1. Methods 与 Experimental Design；
2. Results；
3. Related Work；
4. Discussion；
5. Introduction；
6. Conclusion、Abstract 和标题；
7. Appendices、reproducibility、rubric/PDF audit。

不要按 Day1--Day13 写实验流水账。全文按“预测提升是否存在 → 复杂模型是否增加
价值 → 离线提升是否进入闭环 → adaptive 是否支配 fixed controls”递进。

## 2. 完整章节骨架

### 1 Introduction

- give-way prediction 与 risk-aware planning 的耦合问题；
- 原始 adaptive-vs-fixed 问题为什么必须同时检查 predictor；
- 文献缺口：offline metric、model complexity 与 closed-loop utility 之间缺少受控连接；
- 唯一中心论点；
- RQ1--RQ4 与 H1--H4；
- 四项贡献：task adaptation evidence、matched model evidence、corrected
  translation test、adaptive frontier re-evaluation。

### 2 Related Work

- risk-aware SMPC、fixed/adaptive risk 与 safety supervision；
- multimodal motion prediction、ADE/FDE/NLL 与 calibration；
- interaction-aware/Transformer prediction 与 limited-data model comparison；
- prediction-aware planning 与 open-/closed-loop mismatch；
- gap synthesis：本论文不是通用 SOTA architecture，而是受控的
  model--system translation study。

### 3 Problem Formulation

- ego/target state、prediction horizon、GMM output；
- risk constraint 与 fixed/adaptive policies；
- predictor stack、solver、supervisor、executed trajectory；
- 四个 estimands 与不做的 causal claims。

### 4 Methodology

- Town05 scenario、routes、assertive/reactive target；
- 200-rollout dataset、160/20/20 rollout split、raster/sequence representation；
- B0/B1/B2-M/B2-D/T1/T2；
- frozen training/validation/test/calibration protocol；
- physical baselines、input ablations、training-budget audit；
- corrected implementation 与 R2 deployment gate。

### 5 Experimental Design

- offline selection：5 variants × 3 seeds；
- one-shot frozen test 与 B0/physical controls；
- corrected R3：2 predictors × 4 policies × 2 styles × 5 init groups = 80；
- event-clock completion、actual-bbox separation、binary guards；
- paired clusters、bootstrap、exact sign flip、Holm families；
- legacy diagnostics 与 corrected primary evidence 的隔离。

### 6 Results

#### 6.1 Data and protocol integrity

报告 200 rollouts、split、no leakage、covariate balance 与 80/80 R3 completion。

#### 6.2 H1: task adaptation

报告 B1 vs B0 的 NLL/ADE/FDE effect 以及 physical-baseline 5/5 direction。

#### 6.3 H2: Transformer added value

报告 T1 vs B2-M、T2 vs B2-D 的相反方向，说明 configuration/fairness boundary。

#### 6.4 R3 manipulation validity

报告 40/40 checks，证明部署中确有预测差异，不把它当新独立 benchmark。

#### 6.5 H3: corrected closed-loop translation

引用 `table_r3_h3_translation.csv` 和 `figure_r3_h3_translation.svg`，核心是
2/8 directional cells，不把 Holm p 写成显著。

#### 6.6 H4: adaptive dominance

引用 `table_r3_h4_dominance.csv` 和 `figure_r3_h4_dominance.svg`，核心是
3/12 comparisons。

#### 6.7 Reliability and diagnostics

零 observed binary failures、solver/policy implementation audit；随后用独立小节
报告 raster dominance、sequence use、active-tail calibration 和 legacy timing
mechanisms。

### 7 Discussion

- 为什么 simple adaptation 在小而窄的分布中胜出；
- 为什么 sequence use 不等于 sequence model superiority；
- 为什么 calibrated predictor-stack 的 offline gain 不保证 closed-loop gain；
- adaptive risk 在没有 universal dominance 时仍有什么价值；
- small n、configuration fairness、single-map、tail size、binary endpoint 与
  calibration confounding；
- future work：cross-map、更多 clusters、tail enrichment、matched calibration
  factorial、larger interaction models。所有这些都不属于当前论文必做实验。

### 8 Conclusion

按 H1--H4 顺序各回答一句，最后以“必须联合评估 prediction 与 downstream
risk-control context”收束，不添加新结果。

## 3. 每个 Results 段落的固定模板

1. Question/Hypothesis；
2. Treatment、control 与 independent unit；
3. Effect size、单位和 paired direction；
4. interval/exact/Holm 或样本边界；
5. verdict；
6. 不可外推的范围。

每个数字必须来自 M1 evidence ID 或 A2 canonical table，不能从日志、记忆或旧
Day10--12 文档复制。

## 4. 图表优先级

主文必须有：

- dataset/split schematic；
- model configuration comparison；
- frozen offline result；
- corrected R3 H3 translation；
- corrected R3 H4 dominance；
- four-hypothesis verdict table；
- threats-to-validity table。

Legacy timing/calibration figures可放 Discussion 或 appendix，并在 caption 中明确
`secondary diagnostic; legacy implementation; not pooled with R3`。
