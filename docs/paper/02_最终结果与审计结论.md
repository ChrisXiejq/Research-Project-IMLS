# 最终结果与审计结论

## 1. 总结

现有证据已经足够支撑一篇以机器学习为中心、结论边界清楚的毕业论文，不再需要
大型 CARLA 仿真。最有价值的结果不是“Transformer 或 adaptive risk 获胜”，而是：
强离线预测提升真实存在，但额外模型复杂度和系统级收益都不是自动成立的。

## 2. 四个核心判定

### H1 — 有边界地支持

B1 相对 frozen B0：

- test NLL 降低 0.314 nats/step；
- top-1 ADE 降低 1.193 m；
- top-1 FDE 降低 2.555 m；
- 相对 CV、clipped CA、train-mean 三种物理基线，五个 test init groups
  的 ADE/FDE 均为 5/5 同方向；
- R3 的 40/40 metric--policy--style manipulation checks 中，B1 在每个
  paired init group 都优于 B0。

结论：任务适配在当前分布内带来大且一致的预测提升。R3 的 40/40 是部署时
manipulation validity，不是第二个独立 offline benchmark。

### H2 — 未获支持

- T1 test NLL 为 2.003746，B2-M 为 2.024409：T1 略好；
- T2 test NLL 为 1.878148，B2-D 为 1.872789：T2 略差；
- 两组对应比较方向不一致，且都未超过简单 B1。

结论：在冻结数据、训练与选择协议下，测试的 Transformer adapters 没有显示一致
额外收益。不能写“Transformer 无效”，因为参数量不匹配、10/15 训练到 epoch
ceiling，而且实验只覆盖有限架构和预算。

### H3 — 普遍转化假设未获支持

Corrected R3 中，B1 相对 B0 只有 2/8 policy × target-style cells 同时满足：

1. completion 更快；以及
2. footprint separation 不差。

其余六个 cells 至少有一个方向不满足。全部 Holm-adjusted tests 均为
non-confirmatory。

结论：离线预测提升并没有稳定转化为联合闭环收益。允许写“conditional
translation”或“universal claim not supported”，不应写成证明 B1 在闭环无用。

### H4 — 普遍支配假设未获支持

Adaptive risk 在 12 个 prespecified predictor × style × fixed-comparator
comparisons 中只支配 3 个：

- B0/assertive 相对 fixed medium；
- B1/reactive 相对 fixed aggressive；
- B1/reactive 相对 fixed medium。

其余 9/12 不支配。结论是 adaptive risk 是 context-dependent operating
point，不是 universal winner。

## 3. R3 完整性和安全端点

- 80/80 prespecified rollouts 完成；
- all formal tables、analysis、stop gate 和 verified archive 通过；
- adaptive solver identity 4/4 cells 正确；
- 20/20 adaptive rollouts 存在 within-rollout variation；
- fixed comparators across-init 最大数值范围约 4e-15；
- native collision、footprint collision、fixed-geometry yield failure 和
  completion failure 均未观察到。

最后一项说明所有 arms 在该 nominal matrix 中可行，但 binary endpoints 没有区分
能力，不能写成“同样安全”或“零风险”。主要安全证据是连续 footprint separation。

## 4. 机制与敏感性证据

以下结果可以帮助 Discussion，但不是新的 headline hypotheses：

- B1 的 raster shuffle 对 ADE 影响明显，past shuffle 的 aggregate ADE 变化接近
  零，因此应称 B1 为 raster-dominant，而非有效 target-history modelling；
- T1/T2 对 sequence shuffle/zero 有响应，说明 H2 未获支持不是因为完全忽略输入；
- legacy shifted response-active subset 暴露 calibration tail failure，但样本只有
  15 windows、6 rollouts、3 init groups；
- legacy timing analysis 显示 solver、supervisor 和 physical margin 同时变化，
  因而不能把 supervisor 识别成唯一主因；
- callback-filtered 15-run sensitivity 保持 architecture ranking，只排除该替代
  解释，不替代原 primary experiment。

这些 legacy analyses 必须标成 diagnostic/post-hoc，并与 corrected R3 分开报告。

## 5. 审计后仍存在的限制

1. 只有五个独立 init groups，无法获得双侧 exact p<0.05；
2. B1/Transformer 不是 parameter-matched，H2 只能做 configuration-level 判定；
3. B1 closed-loop treatment 包含 frozen calibration；
4. 单 Town05 give-way、单几何、2 s horizon，不能外推其他地图或真实道路；
5. rare active-tail 很小，只能提示 calibration risk；
6. R3 binary failures 为零，安全端点主要依赖连续 margin；
7. fixed policies 是三个预设 operating points，不是完整连续 Pareto frontier；
8. legacy 与 corrected implementation 不能 pooling。

这些限制需要在正文中透明处理，但都不是继续开启大型实验的理由。

## 6. 论文可以和不可以声称什么

可以声称：

- B1 在冻结分布内以较大幅度改善预测；
- tested Transformers 未建立一致额外优势；
- corrected R3 不支持统一 offline-to-closed-loop transfer；
- adaptive risk 不普遍支配三个 fixed comparators；
- predictor、risk policy 和 target style 共同决定闭环效果。

不可以声称：

- Transformer 在自动驾驶中普遍无效；
- B1 weights 单独导致闭环变化；
- supervisor 是结果的唯一主因；
- adaptive risk 被彻底证明无效；
- arms 统计等价、绝对安全或可推广到真实道路；
- p<0.05 显著或跨地图 generalisation。
