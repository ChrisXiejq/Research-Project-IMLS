# 论文实验与写作统一指导

本文档是当前 dissertation 的主指导书。后续判断实验价值、选择 baseline、设计 ablation、解释结果和写论文结论时，以本文档为准；完整历史细节保留在 `docs/architecture/Give_Way_SMPC_Experiment_Changelog.md`。

## 1. 当前总判断

论文不再押注于证明：

```text
adaptive-risk SMPC 在最终执行轨迹上稳定、全面优于 fixed-risk SMPC。
```

当前更有研究价值、也更能解释已有正负结果的主线是：

```text
在带 runtime safety supervisor 的 rule-constrained give-way intersection 中，研究 uncertainty-aware risk adaptation 应该放在什么责任层级，才会真正影响 closed-loop behaviour，而不是只在 solver log 中可见。
```

换句话说，论文不只讨论：

```text
adaptive-risk 是否比 fixed-risk 更快或更安全？
```

而是讨论：

```text
当 rule-aware supervisor 仍拥有 nominal yield / stop authority 时，risk-aware SMPC 的贡献为什么会被 final executed trajectory 掩盖？当 nominal yield responsibility 从 supervisor 转移到 SMPC/risk layer 后，fixed-risk frontier 和 adaptive-risk 是否开始分离？
```

这条线比“adaptive 必须赢 fixed”更强，原因如下：

- give-way 场景有明确 right-of-way 约束，rule-aware supervisor 是合理的 runtime safety assurance，不是实验作弊；但 supervisor 的 authority level 会决定 planner contribution 是否可见。
- 现有 v12/A1/A2 结果已经说明：在 shared reduced supervisor 下，fixed/adaptive final metrics 经常接近，普通 risk-schedule ablation 不足以形成强 claim。
- 这不是简单 negative result，而是指向一个架构层假设：risk schedule 的价值取决于 responsibility allocation。只改 risk allocation，不改 nominal yield ownership，adaptive 的差异容易停留在 solver layer。
- 因此下一步最有价值的实验不是继续微调 speed / arrival gap / no-pre / no-post，而是做 supervisor authority sweep，尤其是 A3 `risk-owned-yield`。

因此最终论文应写成 risk-aware planning under safety supervision 的架构分析论文，而不是单纯算法胜负论文。

## 2. 文献定位

相关文献通常不会只证明一个 risk setting 在所有指标上支配另一个，而是围绕 uncertainty-aware planning 的 safety、mobility、conservatism、feasibility 和 computation 做 trade-off 分析。

可以借鉴的文献脉络：

| 文献方向 | 常见论点 | 对本文的启发 |
| --- | --- | --- |
| SMPC with multimodal predictions at intersections | 用 chance constraints 处理多模态交通参与者预测，评估 mobility、comfort、conservatism 和 computation。 | 本文应把 CARLA closed-loop give-way 作为 uncertainty-aware planning evaluation，而不是只追 adaptive/fixed 单点胜负。 |
| Chance-constrained MPC under GMM uncertainty | nominal / robust / contingency planner 形成不同 conservatism-performance profile。 | fixed-risk frontier 和 adaptive-risk 应解释为不同 trade-off profile。 |
| Learning-based SMPC for uncontrolled intersections | stochastic formulation 能避免对低概率未来过度保守。 | 可以强调 learned prediction 与 probabilistic planning 减少不必要保守。 |
| Rule-aware safety checker / supervisor | learning or MPC planner 常与 rule-based safety layer 组合，安全层 intervention 需要量化。 | supervisor 是合理架构，但必须隔离其贡献，不能把 supervisor 贡献归给 adaptive-risk。 |
| Online / adaptive risk allocation | fixed risk allocation 简化优化，但 optimal risk allocation 会随场景阶段变化。 | adaptive-risk 的主要贡献应写成 interpretable phase-dependent allocation；若 final metrics 不强，应写 limitation。 |

本文应避免声称直接数值超越某篇参考论文。更合适的 positioning 是：

```text
This dissertation studies risk-aware SMPC under rule-aware safety supervision, focusing on when adaptive risk allocation affects closed-loop behaviour and when it is hidden by the supervisor's nominal yield authority.
```

## 3. 推荐论文主旨

推荐题目方向：

```text
Risk-aware Stochastic MPC under Rule-aware Safety Supervision for Give-way Intersections
```

主问题：

```text
在带 rule-aware safety supervisor 的无信号 give-way intersection 中，risk-aware SMPC 的贡献应在 final executed trajectory、nominal planner output，还是 supervisor intervention boundary 上评价？怎样的 planner-supervisor responsibility allocation 才能让 adaptive risk 真正影响 closed-loop behaviour？
```

主结论目标：

```text
在 high-supervisor-authority regime 中，fixed-risk 和 adaptive-risk SMPC 的 final behaviour 会被 rule-aware supervisor 部分压缩到相似轨迹；这解释了 v12/A1/A2 中 adaptive final-metric advantage 不稳定的原因。真正关键的问题是 nominal yield ownership：当 yield responsibility 从 deterministic supervisor 向 SMPC/risk layer 转移时，risk policy separation 是否出现，以及 adaptive risk 是否能降低 supervisor burden / nominal-final mismatch / emergency intervention，同时保持安全和效率。
```

可以写的 contribution：

1. 构建 CARLA give-way closed-loop pipeline：fine-tuned multimodal predictor、chance-constrained SMPC、rule-aware supervisor 和 post-CARLA safety gate。
2. 系统诊断 conservative early stop，证明主要来自 supervisor / yield logic，并通过 reduced-intervention、executable approach braking 和 planner-ownership stress 把停车点收紧到安全可用的 v12 baseline。
3. 设计 fixed-risk frontier 和 adaptive-risk 对照，展示 risk setting 影响 safety-efficiency-feasibility trade-off；同时避免单点 fixed baseline 的不公平比较。
4. 通过 A1/A2 证明普通 difficulty sweep 和 risk-schedule ablation 不足以稳定暴露 adaptive advantage，提出 `risk ownership` / `supervisor authority` 作为更深层解释。
5. 通过 A3 supervisor-authority experiment 检验：减少 nominal supervisor takeover 后，fixed/adaptive policy separation 是否增强，adaptive 是否能承担更多 nominal yield responsibility。

不要写：

```text
Adaptive risk universally dominates fixed risk.
Adaptive risk alone guarantees safe yielding.
The fine-tuned predictor solves prediction in general.
The v12 close-stop success is an adaptive-risk contribution.
```

### 6.2 当前唯一推荐新增实验：A3 supervisor-authority / risk-owned-yield

当前已经完成的 v12/A1/A2 足以说明 shared supervisor 下 adaptive final-metric advantage 不稳定；如果论文要有更深的问题意识，下一步应只做 A3 architecture experiment：

```text
A3 risk-owned-yield:
减少 nominal deterministic supervisor stop takeover；
保留 emergency braking-distance guard 和 footprint-clearance guard；
让 SMPC reference / risk layer 承担更多 nominal yield/stop preparation。
```

目的不是重新调一个更好 baseline，而是回答：

```text
policy separation 是否随着 supervisor nominal authority 降低而增强？
adaptive-risk 是否能在较少 supervisor takeover 的情况下保持 safety/efficiency，并减少 nominal-final mismatch 或 emergency intervention？
```

推荐实验矩阵：

| Arm | 含义 |
| --- | --- |
| fixed aggressive | static low tightening，测试是否安全 margin 不足或需要 emergency guard。 |
| fixed medium | static default frontier point。 |
| fixed conservative | static high tightening，测试是否过保守或 infeasible。 |
| adaptive floor_weak | phase-aware adaptive risk，在 risk-owned-yield regime 下测试是否更稳。 |

推荐 difficulty：

```text
init01
target_speed=9.0
target_start_offsets="-3.0 0.0 3.0"
```

实验实现状态：

| 项 | 内容 |
| --- | --- |
| 新 agent 开关 | `yield_risk_owned_yield_enabled`，默认 `false`，不影响 v12 frozen baseline。 |
| A3 tuning | `core/scripts/carla/scenarios/tuning_configs/give_way_reduced_clear_path_release_v13_risk_owned_yield.json` |
| A3 run script | `core/scripts/carla/run_give_way_init01_v13_risk_owned_yield.sh` |
| architecture change | reduced supervisor 不再因 nominal overlap / hold 条件接管；只保留 emergency braking-distance 和 footprint-clearance takeover。 |

A3 成功时的写法：

```text
When nominal yield ownership is shifted from the deterministic supervisor to the SMPC/risk layer, risk-policy separation becomes observable. Adaptive risk can then be evaluated not only by final completion/safety, but also by supervisor burden, emergency intervention, and nominal-final mismatch.
```

A3 不成功时的写法：

```text
Even after reducing nominal supervisor takeover, fixed-risk frontier remains competitive. This suggests that adaptive-risk dominance is not guaranteed by risk scheduling alone; the main robust contribution is identifying the boundary between planner risk allocation and runtime safety authority.
```

因此 A3 是当前唯一值得新增的高价值实验。它可以增强论文 claim；即使失败，也能作为 responsibility allocation 的负结果写进 Discussion。

Reduced intervention, executable approach braking, and planner-ownership stress reduce unnecessary conservative stopping while preserving post-CARLA give-way safety in the validated scenarios.
