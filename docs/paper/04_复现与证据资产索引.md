## 6. 不可变规则

1. 不手改 generated CSV/JSON/SVG 中的值；
2. 不删除 raw runs、completion marker、manifest 或 hash record；
3. 不把 simulation steps/windows 当独立重复；
4. 不混合 legacy 和 corrected estimates；
5. 不在看到 R3 或 SF4 方向后重新定义 outcome、dominance 或 collection rule；
6. SF4 达到 80/80 integrity-valid 后不扩展 treatment、地图或 init；
7. 如发现数值问题，修改 generator，重跑 A2/M1，并保留 provenance。

## 7. 论文引用证据的方法

正文只放少量关键数字和可读表图。源代码中的 provenance comment 或 appendix
记录相应 M1 evidence ID；不在正文打印 82 条 manifest。最终 Q1 audit 重新解析
全部 locator/value 并检查论文数字，确保 PDF、表格与冻结证据一致。SF1--SF4
结果进入版本库后，必须重建 M1/W1 并重新运行 Q1；2026-08-09 的 Q1 receipt
只代表 supervisor-feedback amendment 之前的 evidence cut。
