# 复现与证据资产索引

## 1. 唯一论文资产入口

```text
docs/paper/generated/paper_assets_v1/
```

核心文件：

- `paper_results_manifest.json`：210 stable result IDs；
- `paper_tables.md`：8 张表的 Markdown preview；
- `table01`–`table08.csv`：canonical tables；
- `figures/figure01`–`figure08.svg`：可编辑主图；
- 同名 PNG：Word/PPT fallback；
- `figures/figure_captions.md`：canonical captions；
- `paper_claim_evidence_matrix.csv`：H1–H8 → IDs → figures；
- `paper_key_results.csv`：正文关键数字；
- `paper_asset_inventory.csv`：file hashes/sizes；
- `PAPER_EVIDENCE_PACKAGE_COMPLETE.json`：package completion gate。

## 2. Final audit

```text
docs/paper/generated/final_audit/FINAL_THESIS_EVIDENCE_AUDIT.json
```

该文件检查 Day6–Day14 的 count、split、selection/test separation、formal matrices、collision sensitivity 和 paper package integrity，并列出论文必须处理的 8 个 methodological warnings。

运行：

```bash
python3 core/scripts/models/audit_final_thesis_evidence.py
```

## 3. 重新生成论文表格

```bash
python3 core/scripts/models/build_paper_results_manifest.py
```

它从 Day7/8/10/12/13 的 canonical JSON/CSV 重新生成 result manifest 和 tables。禁止手改生成的数字。

## 4. 重新生成 SVG 图片

```bash
python3 core/scripts/models/build_paper_figures.py
```

SVG 使用 Python standard library，应该确定性生成。

PNG 依赖 Node + Sharp；当前 Codex runtime 示例见 `generated/paper_assets_v1/README.md`。SVG 是 canonical，PNG 只是兼容输出。

## 5. 完整性审计
