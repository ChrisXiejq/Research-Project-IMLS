> 更新时间：2026-08-02（Day13 敏感性与论文数字 Manifest 完成）
>
> 用途：记录从早期 planning 探索到 Day11 正式闭环稳健性实验的完整证据。后续论文级收尾以 `Day11后论文级实验审计与Day12至Day14执行方案.md` 为准。

## 1. 当前证据边界

已完成实验足以支持：

1. 原系统的 conservative early stop 主要受 shared supervisor/yield logic 影响；
2. v12 能在相同 supervisor 下安全地将停车点推进到约 4.5 m；
3. fixed-risk 必须作为 frontier，而不是单点 baseline；
4. speed、arrival-gap 和 phase schedule 的局部调整没有稳定证明 adaptive dominance；
5. A3 降低 nominal supervisor authority 后仍安全，并让 policy separation 更可见；
6. V2 simple adaptation、matched MLP 与 Transformer variants 已完成统一训练和冻结 test；
7. T1/T2 的 zero/shuffle ablation 证明模型使用了显式 interaction sequence，但 Transformer 未超过简单 B1 adaptation；
8. B1 的强离线改善没有形成跨 risk/timing 的单调闭环收益；
9. aggregate calibration 无法可靠迁移到 response-active tail。

不能支持：

- adaptive risk 普遍优于 fixed-risk frontier；
- fine-tuning 在所有 risk/timing 条件下都改善 closed loop；
- 当前 Transformer 学到了因果 interaction 或能跨地图泛化；
- mode entropy 下降等价于概率校准改善；
- 305 个 test windows 是 305 个独立场景。

## 3. 关键定量结果

### 3.1 Supervisor ablation

| Arm | First stop before | First stop reduced | Wait before | Wait reduced | Clearance delay before | Clearance delay reduced |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| fixed | 8.403 m | 5.263 m | 8.040 s | 4.200 s | 3.720 s | 1.440 s |
| adaptive | 8.402 m | 5.263 m | 8.120 s | 4.160 s | 3.720 s | 1.400 s |

### 3.2 A3 risk-owned-yield

- `-3.0 m`：adaptive `11.25 s / 1.285 m footprint`；fixed frontier 约 `10.60 s / 1.312–1.325 m`。
- `0.0 m`：adaptive `10.45 s / 1.301 m`；fixed aggressive `10.20 s / 1.337 m`。
- `+3.0 m`：adaptive margin 最高 `1.852 m`，但 completion `11.45 s`，慢于 fixed medium `9.85 s`。

结论：A3 证明较低 nominal supervisor authority 下系统仍安全，但不证明 adaptive 全面优于 fixed。

### 3.3 Repeated-context Transformer pilot：旧 training-loader contract

Test split 来自 init 46–50 的 5 个 rollouts，共 305 个 full-horizon windows：

| Metric | B1 fine-tuned MultiPath | T0 repeated-context Transformer |
| --- | ---: | ---: |
| top1 ADE | 0.02680 m | 0.02556 m |
| top1 FDE | 0.03575 m | 0.03281 m |
| P90 minADE | 0.04575 m | 0.03969 m |

所有 test windows 的最佳 anchor 相同。误差下降是 pilot positive signal；entropy 收缩在没有 NLL/coverage 前也可能是 overconfidence。

T0 仍有点预测方向的改善，但 legacy input mismatch、较高绝对误差和 coverage failure 阻止更强结论。

## 4. 数据与统计限制

- V1 dataset 的 target 是不读取 ego 的恒速 `StraightLineAgent`。
- Base raster 已包含 ego occupancy/history，不能称为纯 target-only baseline。
- V1 split 是 40/5/5 independent rollouts，不是按 10,236 个 windows 随机切分。
- 当前 test 只有 5 个独立 inits，正式统计必须 rollout-level 聚合。
- 同一 init 下的多种 style/risk/offset 是重复条件；正式推断必须进一步按 init 聚类，不能只按 rollout condition 计数。
- T0 使用单帧 8D context 在历史维重复，不是完整 temporal interaction encoder。
- 当前 GMM covariance conversion 使用 `exp(abs(raw))`，正式 calibration 前必须审计。
- Day10 pooled analysis 已升级为 v3 init-cluster inference；136 个 effect means 不变，旧 condition-level p 值已废止。
- 完整 V2 dataset、Day8 model weights、Day10/Day11 full snapshots 已有服务器外第二份 SHA-256/tar 验证副本。
- Day6 的 253 个 collision callbacks 对应 6 个 training-only target–infrastructure rollouts、16 个 contact episodes、62 个 unique frames，不能写成 253 次独立车辆碰撞。由于旧数据缺少 per-rollout CARLA frame anchor，逐窗口精确归因不可识别；论文使用 162 个 usable train windows 的保守上界并补 filtered sensitivity。
